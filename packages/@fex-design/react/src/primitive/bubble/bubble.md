# Bubble

Styled compositional surface for conversational content. `Bubble` resolves `side` from itself, an enclosing `Message`, or `start`. Compose `BubbleContent`, `BubbleActions`/`BubbleAction`, and `BubbleReactions`/`BubbleReaction`; action items default to Toggle behavior and accept a render function for a fully custom element.

`BubbleGroup` arranges consecutive surfaces without owning message data.
